# 本次任务：补一个「思考中」等待态（只改前端）

## 背景

实测发现：点击「生成」后，模型会先输出一段不展示的推理内容，导致输出区**最长空等 11 秒**才有第一个字，
期间界面没有任何反馈，用户会以为卡死了。

## 要求（严格只改前端，不要动 server.js / lib/*）

1. 点击「生成」后，**立刻**在输出区显示等待状态：`思考中… 已等待 N 秒`，N 每 200ms 刷新一次。
2. 第一个字符（或 done/error）到达后，等待状态消失，正常显示流式内容。
3. 等待期间「生成」按钮仍显示「停止」，点击后停止并清除等待态。
4. 流式输出过程中，输出区自动滚动到底部（用户手动上滚时不强制打断，简单实现即可）。
5. 出错时，等待态也要消失，并显示错误信息（保持现有错误处理）。
6. 不改动 SSE 协议、接口、后端逻辑；提示文案与现有风格一致。
